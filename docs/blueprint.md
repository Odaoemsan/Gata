# **App Name**: GORA HYIP

## Core Features:

- Investment Plans Display: Display available investment plans with clear details such as interest rates, durations, and minimum/maximum investment amounts.
- User Authentication: Secure user registration, login, and password reset functionality.
- Transaction History: Record all transactions made within the application for users to easily consult
- Referral System: Implement a referral system where users can invite others and earn rewards.
- Earnings Calculation: Calculates the expected earnings based on the investment plans and displays it to the user before the user confirms their action.
- Investment and Withdrawal Processing: Allow users to deposit and withdraw funds using various payment methods.

## Style Guidelines:

- Primary color: Deep sky blue (#00BFFF) to evoke trust and financial growth.
- Background color: Very light grayish blue (#E6F7FF). Provides a clean and professional backdrop.
- Accent color: Bright turquoise (#30D5C8) for interactive elements and call to action buttons.
- Headline font: 'Poppins', a geometric sans-serif to convey modernity, suitable for headlines and short amounts of body text.
- Body font: 'Inter', a grotesque-style sans-serif, which makes for very readable longer form text.
- Use modern, minimalist icons to represent different features and investment options.
- Design a clean, intuitive layout with a clear hierarchy of information on the homepage.
- Use subtle animations and transitions to enhance user engagement.
